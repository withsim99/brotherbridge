Quick Start & Live Commands

Up and printing in 2 minutes.

Enter your host Android phone's IP below to customize every setup URL, PowerShell one-liner, CUPS command, and `curl` scan workflow automatically.

1

Active USB OTG Connection (Mandatory)

The host Android device must support USB OTG and remain physically connected to the Brother printer/scanner via an OTG cable/adapter with Android USB permission granted.

2

Unrestricted Background Battery

Disable Android Battery Optimization (App Info → Battery → Unrestricted). On Xiaomi/MIUI, Samsung, OnePlus, Vivo, and Oppo, also lock BrotherBridge in Recent Apps for 24/7 uptime.

PRO TIP Enable Auto-Start Server on USB OTG in Settings, and optionally use a USB OTG Power Y-Splitter / Powered Hub so your host phone stays continuously charged.

Set Up the Spare Android Host Server

Android 7.0+ · USB OTG
  1. 1 Install BrotherBridge on your spare Android device connected to your Wi-Fi or mobile hotspot.
  2. 2 Connect your USB-only Brother printer via the USB OTG cable and tap Allow on the Android USB permission prompt.
  3. 3 Open Android App Info → Battery and set usage to Unrestricted for 24/7 background hosting.
  4. 4 Tap Server on the Home screen and toggle Remote Server ON (or enable Auto-Start on USB OTG in Settings).
  5. 5 Note your live IPP print endpoint & verify reachability in any browser at http://192.168.1.50:8631/:
http://192.168.1.50:8631/ipp/print

Wireless Printing on Windows 10 / 11

Microsoft IPP Class Driver · Zero Brother Drivers

BrotherBridge natively supports IPP 2.0, HTTP chunked transfer decoding, Expect: 100-continue, IEEE 1284 Device ID, and image/pwg-raster for Windows' built-in driver.

Fastest — One-Line PowerShell Setup 
Add-Printer -IppURL "http://192.168.1.50:8631/ipp/print"

Option A — Automatic Discovery (mDNS)

  1. Open Settings → Bluetooth & devices → Printers & scanners → Add device.
  2. Wait a few seconds for BrotherBridge to appear and click Add device.

Option B — Manual URL (If mDNS Blocked)

  1. Go to Add device → Add manually → Select a shared printer by name.
  2. Paste http://192.168.1.50:8631/ipp/print.
  3. If prompted, select Microsoft → Microsoft IPP Class Driver.

Wireless Printing on macOS

Bonjour · AirPrint / Generic PDF

Automatic (Bonjour)

  1. Open System Settings → Printers & Scanners → Add Printer.
  2. Select BrotherBridge under the Default tab.
  3. Keep Use: AirPrint / Generic PDF Printer and click Add.

Manual (IP Tab)

  • Protocol: Internet Printing Protocol - IPP
  • Address: 192.168.1.50:8631
  • Queue: ipp/print
  • Use: Generic PDF Printer

Wireless Printing on Linux (CUPS)

IPP Everywhere · Avahi

Open Settings → Printers → Add for automatic Avahi/CUPS _ipp._tcp discovery, or register instantly from your terminal:

CUPS CLI One-Liner (or http://localhost:631) 
lpadmin -p BrotherBridge -E -v ipp://192.168.1.50:8631/ipp/print -m everywhere

Connect Wirelessly from Another Android Phone

Print + 2400 DPI Scan + System Plugin
  1. 1 Install BrotherBridge on your daily Android phone or tablet on the same Wi-Fi / Hotspot.
  2. 2 Tap Scan for Printers on Home for automatic mDNS/UDP discovery—or tap 3-dot menu → Add IP Manually! and enter 192.168.1.50 and port 8631.
  3. 3 Print or scan at up to 2400 DPI right inside the app, or enable BrotherBridge in Android Settings → Printing to print from Chrome, Drive, Gmail, Photos, and Files (stays connected even after closing BrotherBridge).

Developer Integration

Asynchronous HTTP/JSON Scan API.

Build desktop tools or shell scripts directly against port 8631. Features queued jobs, X-Scan-Sha256 integrity headers, and automatic recovery for unacknowledged scans.

Companion Desktop Client
@withsim99/BrotherBridge-PC-Client ↗
Method Endpoint Description
GET /api/status Check USB OTG connection, model name, toner/drum/paper health, and server status
GET /api/scan/capabilities Query scanner availability, busy state, flatbed/ADF support, and model
POST /api/scan/start Start (or queue) a scan job; returns HTTP 202 with a jobId
GET /api/scan/jobs/<jobId>/progress?deviceId=<id> Poll job status (QUEUED → RUNNING → READY / FAILED / CANCELED) and page metadata
GET /api/scan/jobs/<jobId>/page/<index>?deviceId=<id> Download scanned page (image/jpeg) with X-Scan-Sha256 & X-Scan-Size-Bytes
POST /api/scan/jobs/<jobId>/ack Acknowledge verified receipt (sha256 + receivedBytes) to clear the host vault copy
GET /api/scan/pending?deviceId=<id> Recover any completed but unacknowledged scans after a network disconnect
POST /api/scan/jobs/<jobId>/cancel Cancel an active or queued scan job immediately
scan_workflow.sh — Live IP Synced 
# 1. Start a 300 DPI color flatbed scan (returns JSON with "jobId")
curl -X POST "http://192.168.1.50:8631/api/scan/start" \
  -H "Content-Type: application/json" \
  -d '{
    "deviceId": "my_pc_01",
    "clientName": "My PC",
    "source": "FLATBED",
    "colorMode": "COLOR",
    "dpi": 300,
    "pageSize": "A4",
    "brightness": 50,
    "contrast": 50
  }'

# 2. Poll progress until status is "READY"
curl "http://192.168.1.50:8631/api/scan/jobs/<JOB_ID>/progress?deviceId=my_pc_01"

# 3. Download page 1 as JPEG (returns X-Scan-Sha256 header)
curl "http://192.168.1.50:8631/api/scan/jobs/<JOB_ID>/page/1?deviceId=my_pc_01" \
  --output scanned_page_1.jpg

# 4. Acknowledge verified receipt (cleans up the host vault copy)
curl -X POST "http://192.168.1.50:8631/api/scan/jobs/<JOB_ID>/ack" \
  -H "Content-Type: application/json" \
  -d '{
    "deviceId": "my_pc_01",
    "pageIndex": 1,
    "sha256": "<SHA256_OF_SCANNED_PAGE_1>",
    "receivedBytes": 123456
  }'

Troubleshooting & FAQ

Common edge cases, solved.

Verify two requirements: (1) your Brother printer is powered on and physically connected via a working USB OTG cable with Android USB permission granted, and (2) Unrestricted Background Battery Usage is enabled in Android App Info → Battery.
Some Android OEMs (Xiaomi/MIUI, Samsung, OnePlus, Vivo, Oppo) enforce aggressive background process limits. In addition to setting Battery to Unrestricted, lock BrotherBridge in Recent Apps and disable "Pause app activity if unused" in App Info.
Many Wi-Fi routers and mobile hotspots block multicast traffic (AP Isolation or cross-band 2.4 GHz / 5 GHz isolation). Bypass discovery completely by adding the printer manually using http://192.168.1.50:8631/ipp/print on PC or Add IP Manually! in the Android client.
Confirm the Host phone is still online on the same Wi-Fi network with the Remote Server running. BrotherBridge intentionally keeps the Android Print Service plugin connected even after you close the app, and only disconnects automatically if the host goes offline or you manually choose 3-dot menu → Disconnect Device.
